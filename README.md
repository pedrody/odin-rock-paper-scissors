# odin-rock-paper-scissors

This project is a "Rock paper scissors" game. It was developed as part of the [The Odin Project (TOP)](https://www.theodinproject.com) curriculum, with the goal of practicing introductory programming concepts with JavaScript, such as data types, conditionals, functions, and DOM manipulation.

The project is deployed via GitHub Pages, so you can [try it out here](https://pedrody.github.io/odin-rock-paper-scissors/).
